# Zeiro Executions Service

Database query execution service that handles the actual execution of generated database queries with performance optimization and result processing.

## Overview

The Executions Service is responsible for executing database queries that have been generated by the Chat Service. It provides secure, efficient execution of DynamoDB operations with performance monitoring, result formatting, and asynchronous processing capabilities.

## Core Components

1. **Query Execution Engine** - Direct execution of database queries
2. **Manual Query Interface** - Manual parameter-based query execution
3. **Generated Query Processor** - Execution of AI-generated query parameters
4. **Async Processing Queue** - Background query execution with real-time notifications
5. **Performance Monitoring** - Query performance analysis and optimization suggestions

## Key Features

- **Multi-Operation Support**: Query, Scan, GetItem, BatchGet operations
- **Performance Optimization**: Automatic efficiency analysis and suggestions
- **Async Processing**: Background execution with real-time status updates
- **Security**: Secure credential handling and user authorization
- **Result Formatting**: Structured data output for visualization
- **Error Handling**: Comprehensive error management with user-friendly messages

## API Endpoints

### Query Execution
- `POST /executions/execute` - Execute natural language query directly
- `POST /executions/manual` - Execute query with manual parameters
- `POST /executions/generated` - Execute query with AI-generated parameters

### Async Processing
- SQS-triggered background processing for long-running queries
- Real-time notifications via WebSocket service for status updates

## Query Operations

### DynamoDB Operations Supported

1. **Query Operation**
   - Most efficient for partition key-based lookups
   - Supports sort key conditions and filtering
   - Uses Global Secondary Indexes when needed

2. **Scan Operation**
   - Full table scans for complex filtering
   - Less efficient but necessary for certain queries
   - Automatic optimization suggestions

3. **GetItem Operation**
   - Direct item retrieval with complete primary key
   - Fastest operation for single item access

4. **BatchGet Operation**
   - Multiple item retrieval in single request
   - Efficient for known key sets

### Performance Analysis

The service automatically analyzes query performance and provides:
- Efficiency ratings
- Optimization suggestions
- Alternative query approaches
- Index usage recommendations

## Usage Examples

### Direct Query Execution
```json
POST /executions/execute
{
  "database_id": "db-123",
  "natural_language_query": "Show me recent orders",
  "model": "gpt-4o-mini"
}
```

### Manual Parameter Execution
```json
POST /executions/manual
{
  "database_id": "db-123",
  "operation": "query",
  "table_name": "orders",
  "key_condition_expression": "pk = :pk",
  "expression_attribute_values": {
    ":pk": "ORDER#2024"
  }
}
```

### Generated Query Execution
```json
POST /executions/generated
{
  "query_id": "query-456",
  "execution_id": "exec-789"
}
```
